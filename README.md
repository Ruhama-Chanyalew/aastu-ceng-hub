# AASTU Computer Engineering (GC) Study & Exam Preparation Hub

An all-in-one learning platform and exam preparation system engineered specifically for **Graduating Class (GC)** students in the **Department of Electrical and Computer Engineering** at **Addis Ababa Science and Technology University (AASTU)**.

---

## 🎯 Purpose & Features

- **Textbook-Grounded Lecture Notes:** Replaces incomplete classroom lectures with in-depth, rigorous notes derived directly from the world's most authoritative textbooks (*John J. Craig, Silberschatz & Galvin, Andreas C. Müller & Sarah Guido, Neil Weste, Ian Sommerville, and Raj Kamal*).
- **Interactive Biomechanical & Robotics Visualizer:** An interactive HTML5 Canvas simulator comparing **Human Anatomy** (bones, muscles, nerves, tendons, touch receptors) directly with **Robotic Manipulators** (links, servomotors, harmonic drives, optical encoders, 6-DOF wrist grippers), featuring real-time Forward Kinematics, Analytical Inverse Kinematics, and Denavit-Hartenberg (DH) coordinate frames.
- **End-of-Chapter Assessment Engine:**
  - **Part A:** Conceptual Multiple-Choice Questions (MCQs) with instant grading and detailed engineering rationales.
  - **Part B:** University Final Exam descriptive and analytical short-answer questions with model solutions.
  - **Part C:** Step-by-step worked numerical and derivation problems (e.g. DH parameter tables, transformation matrix derivation, scheduling Gantt charts, k-NN distance calculations).
  - **Part D:** Ethiopian Ministry of Education **National Exit Examination (NEE5108)** benchmark preparation questions.
- **Offline-Ready & Printable:** Fully responsive, zero heavy build tools or npm dependencies needed. Open `index.html` directly or serve via Python. Includes clean print stylesheets for exporting notes to PDF.

## 🚀 Quick Start Instructions

You can run this website instantly using Python's built-in HTTP server:

```bash
# 1. Navigate to the project directory
cd /Users/ruhamachanyalew/.gemini/antigravity/scratch/aastu-ceng-hub

# 2. Start the local server
python3 -m http.server 8000

# 3. Open in your web browser
# Navigate to: http://localhost:8000
```

Alternatively, you can double-click or open `index.html` directly in Google Chrome, Safari, or Microsoft Edge.
